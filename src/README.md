# Дурак

Подкидной дурак по сети: общий игровой протокол, авторитетный сервер и браузерный стол.

## Стек

| Слой | Выбор | Зачем |
| --- | --- | --- |
| `@durka/shared` | TypeScript | Карты, правила, виды партии и JSON-протокол в одном месте |
| `@durka/server` | Node.js, Fastify, WebSocket | Комнаты и единственный источник правды |
| `@durka/client` | Vite, React | Лобби и стол |

Сервер не отдаёт чужие карты. Каждому игроку уходит свой `PlayerGameView`: открытый стол и только его рука.

Ходы (атака, отбой, подкидывание, «беру», «бито») описаны в протоколе, а принимаются в `DurakGame.apply`. Сейчас там заглушка: раздача и синхронизация уже работают.

## Структура

```text
packages/shared/src   карты, canBeat, сообщения клиента и сервера
packages/server/src
  app.ts              HTTP /health и WebSocket /ws
  durak-server.ts     сессии, комнаты, рассылка видов
  rooms/              стол до и во время партии
  game/engine.ts      колода, раздача, вид игрока, apply()
packages/client/src
  net/GameProvider    сокет и состояние
  screens/            лобби, ожидание, стол
  components/         карта и рубашки
```

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Клиент: http://localhost:5173  
Сервер: http://localhost:3001/health  

Два игрока — две вкладки браузера. Создайте стол, передайте код, оба нажимают «Готов», создатель раздаёт карты.

С другой машины в той же сети откройте `http://<ip-этого-компьютера>:5173`. Vite проксирует `/ws` на локальный сервер. Если клиент открыт не через этот Vite, задайте адрес сокета: `VITE_WS_URL=ws://<ip>:3001/ws`.
